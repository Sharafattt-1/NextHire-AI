# NextHire AI - AI Resume Analyzer

## Live Demo

https://nexthire-ai-10.onrender.com

## Project Description

NextHire AI is an AI-powered resume analysis platform designed to help job seekers improve their resumes and make better career decisions. The application allows users to upload their resumes and uses artificial intelligence to analyze the content, identify important skills, evaluate keywords, and provide detailed feedback for improvement. The main goal of this project is to simplify the resume review process by providing users with fast, intelligent, and automated suggestions that can help them create more effective resumes.

The platform is built to assist students, fresh graduates, and professionals who want to optimize their resumes before applying for jobs. By analyzing resume structure, skills, and content quality, NextHire AI helps users understand the strengths and weaknesses of their resumes and provides recommendations to improve their chances of getting noticed by recruiters.

This project is developed using Python and Django for backend development, along with HTML, CSS, and JavaScript for the frontend interface. It integrates the Gemini AI API to generate intelligent resume analysis and personalized suggestions. The application follows secure development practices by storing sensitive information such as API keys using environment variables.

## Features

- AI-powered resume analysis
- Resume upload and processing
- Skill and keyword evaluation
- AI-generated improvement suggestions
- Resume quality feedback
- Simple and user-friendly interface
- Secure API key management

## Setup

To run this project locally, clone the repository, create a virtual environment, install the required dependencies using `requirements.txt`, add the required environment variables in a `.env` file, and start the Django development server using `python manage.py runserver`.

## Usage

Users can upload their resumes, receive AI-generated feedback, identify areas for improvement, and optimize their resumes for better career opportunities.
